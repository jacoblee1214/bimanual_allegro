## 요약

- **목표**: v3 는 공백 동안 마지막 센서 거리를 유지해서, 손이 앞뒤로 움직이면 공백 끝에서 한 번에 튑니다(M7 약점 1). PnP 거리를 쓰면 공백 직전 PnP 오염에서 나빠집니다. 오염이 있어도 v3 보다 나쁘지 않으면서 `depth 단계` 공백의 끝 계단을 줄이는 것이 목표였습니다.
- **v4**: 공백 동안 PnP 가 아니라 **2D 랜드마크 span**(손 크기)으로 거리 변화를 추정합니다. 마지막 센서 프레임의 span 이 앵커이고, 거리 = 마지막 센서 거리 × (앵커 span / 지금 span)^gain. 변화량에는 범위 제한과 프레임당 이동 제한이 있습니다. 센서 프레임에서는 v3(= v2)와 완전히 같고 앵커를 새로 잡습니다.
- **결과**: 이 영상의 모의 공백에서 v4 가 v3 보다 모든 경우의 공백 중 오차와 끝 계단 p50 / p95 에서 낮았습니다. `depth 단계 2s` 끝 계단 p50 은 왼손 90.1 → 23.3 mm, 오른손 97.1 → 22.5 mm 입니다. 오염 경우의 값은 오염 없는 경우와 사실상 같았습니다(v4 는 PnP 거리를 쓰지 않으므로). 즉 목표 두 가지 모두 이 영상에서는 달성했습니다.
- **단서**: gain 0.5 는 이 영상에서 gain 을 훑어 보고 고른 값입니다(**이 영상에 맞춰 고른 값**). 영상 하나, 사람 하나, 공백은 모의입니다. 범위 제한과 프레임당 제한은 이 영상에서는 거의 작동하지 않아서(`v4_loose` 와 거의 같음) 효과를 확인하지 못했습니다. 최대값(max)은 일부 경우에서 v3 보다 컸습니다(5장).

## 2. v4 방법

- `span` = 랜드마크 0, 1, 5, 9, 13, 17 의 중심으로부터의 RMS 화소 거리(깊이 영상 크기 기준 화소). 앵커 span 과 지금 span 은 각각 최근 3 프레임의 중앙값입니다.
- `hold` 프레임: `log(거리 배율)` 의 목표 = `gain × log(앵커 span / 지금 span)`, 이를 ±log(1.5) 로 제한하고, 프레임당 최대 0.03(log) 만 목표 쪽으로 움직입니다. 위치는 v3 와 같이 지금 랜드마크 0 광선 위입니다.
- 기본값은 gain 0.5, 제한 1.5, 프레임당 0.03. gain 0 이면 v3 와 같습니다(시험 있음).
- 선택 기능 `pnp_weight`(기본 0): PnP 의 상대 거리 변화가 span 의 변화와 0.15(log) 안에서 일치할 때만 섞고, 어긋나면(오염) 무시합니다(아이디어 c). 기본은 끄고 평가에서만 0.5 로 켰습니다.
- 시도하지 않은 것: 공백 길이에 따른 가중 감쇠(아이디어 b 의 일부). 범위 제한과 프레임당 제한만 넣었습니다.

## 3. 평가 방법

M7(`m7_hold_v3.md` 3장)과 같습니다. 공백 0.3 / 1 / 2 s, 3 s 부터 0.2 s 간격, `clean` / `depth 단계` / `오염`(공백 직전 0.6 s 동안 PnP × 0.65), 기준은 공백 없는 v2. 같은 표 형식입니다(p50 / p95 / max, mm). 평가 변형:

| 변형 | 내용 |
|---|---|
| `v2`, `v3` | M7 과 같음 |
| `v4` | 위 기본값(gain 0.5) |
| `v4_g10` | gain 1.0(감쇠 없음) |
| `v4_loose` | 범위 제한과 프레임당 제한을 사실상 끔(제한 100) |
| `v4_pnp` | `pnp_weight` 0.5, 일치할 때만 |
| `v3_pnprel_med` | M7 의 PnP 상대 변화 방식(이 영상에 맞춰 고른 값), 참고용 |

## 5. 약점과 개선되지 않은 부분

1. **gain 은 이 영상에 맞춘 값입니다.** gain 0.3~0.7 을 훑었을 때 모두 v3 보다 낫고 0.6 이 가장 좋은 경우가 많았지만(개발 중 확인, 이 보고서의 JSON 에는 gain 0.5 와 1.0 만 있음), 다른 사람의 손이나 다른 움직임에서 같은 값이 맞는다는 근거는 없습니다.
2. **최대값(max)이 항상 낮아지지는 않았습니다.** 필터 뒤 오차 max 가 왼손 `clean 1s` 에서 v3 158.9 → v4 163.2 mm, 오염 1 s 에서도 같습니다. p50 과 p95 는 좋아져도 특정 공백에서 드물게 나빠질 수 있습니다.
3. **span 은 손이 회전해도 변합니다.** 손바닥이 카메라를 향하다 옆으로 도는 움직임은 거리 변화로 오인됩니다. 이 영상에는 그런 움직임이 적을 수 있습니다. 시험하지 않았습니다.
4. **센서 프레임 하나와 span 하나에 앵커를 둡니다.** 마지막 센서 프레임이 틀렸을 때(M7 약점 3)는 v3 와 마찬가지로 시험하지 않았습니다. 랜드마크가 틀리게 잡힌 프레임(MediaPipe 오검출)이 span 을 흔들면 거리가 같이 흔들립니다. 3 프레임 중앙값과 제한으로 줄였지만 확인하지 않았습니다.
5. 영상에서 손이 카메라에 너무 가까워 센서가 끊기는 실제 경우(M7 약점 2)는 이 영상에 없습니다.
6. 노드(`hand_tracker_node_v5`)에 `--fusion v4` 는 만들지 않았고, 실물 카메라와 로봇으로는 시험하지 않았습니다. `WristDepthV4` 는 `fusion_factory` 로 바로 쓸 수 있는 형태이지만 노드에서 돌려 본 적은 없습니다.
7. 평가의 기준은 센서 손목(v2)이지 정답이 아닙니다. 영상 하나(약 33 s), 사람 하나, 공백은 모의입니다.
