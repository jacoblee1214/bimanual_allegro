# R5: 두 팔이 에고 RealSense 로 본 작업자의 두 손을 동시에 따라가기

- 날짜: 2026-10-20
- 실행: 사용자가 직접 실행했습니다(자동 모드 분류기가 `--enable` 실행을 막아, 사용자가 `!` 로 실행). 사용자가 로봇을 지켜봤습니다.
- 분석: Claude Opus 5.5 (총괄)
- 카메라를 다시 설치했습니다.
  - 이번에는 **USB 3.2** 로 붙었고, 컬러 + 깊이 640x480@30 이 30.0 fps 로 나옵니다(이전 USB 2 에서는 시작 불가, `docs/05_ego_camera.md` 4장).
  - IMU 측정: 아래로 **29.1°**, 좌우 −0.8° (이전 44.3°, −5.1°). `config/ego_camera.yaml` 을 갱신했습니다.
  - 이번 실행은 컬러만 썼습니다. 깊이는 아직 쓰지 않습니다.

```bash
# 두 팔 각각 (--ros-args -r __ns:=/left, /right)
arm/xarm_bridge_node_v3.py --side {left,right} --enable --duration 32 --max-joint-speed 0.3 --max-excursion 0.3
arm/arm_follow_node_v6.py --q0-from-robot --position-only --max-joint-speed 0.3 --radius 0.07 --scale 0.5 \
    --joint-box 0.3 --camera config/ego_camera.yaml
# 비전은 하나
vision/hand_tracker_node_v3.py --source realsense --view ego --ray-filter --gpu
```

시작 전 dry run(브리지 `--enable` 없음)에서 두 브리지가 32 s 에 스스로 끝났고, 엔코더는 움직이지 않았습니다. 그때는 화면에 손이 하나만 있어서 두 팔 경로는 이 실행에서 처음 확인했습니다.

## 결과

| 항목 | 왼팔 | 오른팔 |
|---|---|---|
| 손 검출 | 899/899 | 899/899 |
| 손목 샘플 (수락 / 거부 / 재클러치) | 885 / 0 / 1 (시작) | 885 / 0 / 1 (시작) |
| 축별 상관, 지연 0 (앞 / 왼쪽 / 위) | 0.78 / 0.77 / 0.81 | **0.89 / 0.91 / 0.93** |
| 축별 상관, 가장 좋은 지연 | 0.94 / 0.92 / 0.93 (200~260 ms) | 0.92 / 0.94 / 0.94 (140~160 ms) |
| 범위 (손 × 0.5 → 팔 끝, mm) | 233→118 / 44→23 / 153→84 | 105→58 / 53→42 / 99→53 |
| 팔 끝 최대 이동 | 70 mm (반경 70 mm) | 70 mm (반경 70 mm) |
| 관절 최대 변화 (상자 0.3 rad) | 0.202 rad (j4) | 0.280 rad (j5) |
| 관절 속도 최대 (50 ms 구간, 헤더 시각) | 0.321 rad/s | 0.318 rad/s |
| 범위 밖 명령 | 0 | 0 |
| 종료 | 32 s 스스로 정지, state 4, 오류 0 | 같음 |

- 상관은 손 위치 × 0.5 (`R_CB` 로 로봇 축) 와, 측정 관절로 FK 한 팔 끝 위치를 비교했습니다. "가장 좋은 지연"은 팔 끝을 0~600 ms 늦춰 가며 상관이 가장 큰 값을 고른 것입니다.
- 왼손은 앞쪽으로 반경보다 크게 움직였습니다(손 × 0.5 로 233 mm). 팔 끝은 반경 70 mm 에서 잘리므로, 지연 0 상관이 낮은 데에는 이 몫도 있습니다.
- 오른팔 j5 가 상자 0.3 rad 에 0.02 rad 까지 다가갔습니다. 범위를 넓힐 때 가장 먼저 걸릴 관절입니다.
- 브리지 로그 끝의 `[set_state], xArm is not ready to move` 는 정지 명령 때 SDK 가 내는 메시지로, R2 이후 모든 실행에서 같았습니다.

## R4 와 비교 (오른손)

| | R4 (2026-10-19) | R5 |
|---|---|---|
| 추종 / 비전 | v5 / v2 (One Euro) | v6 / v3 (`--ray-filter`, 위치만 보는 차단기) |
| 카메라 기울기 | 44.3° | 29.1° |
| 이상치 차단 (거부 / 재클러치) | 76 / 4 | 0 / 1 |
| 축별 상관 (앞 / 왼쪽 / 위) | 0.44 / 0.85 / 0.60 | **0.89 / 0.91 / 0.93** |
| 손목 프레임간 이동 p50 / p95 | 6.9 / 60.5 mm | 3.0 / 10.3 mm |
| 축별 p95 (앞 / 왼쪽 / 위) | 42.0 / 8.6 / 43.4 mm | 7.5 / 3.6 / 6.5 mm |

왼손은 프레임간 이동 p50 / p95 4.1 / 17.0 mm, 축별 p95 13.6 / 3.3 / 9.5 mm 였습니다. 프레임간 이동에는 실제 손 움직임도 들어 있어 순수한 흔들림은 아닙니다.

개선에는 세 가지가 함께 작용했습니다. 시선 방향 칼만 필터와 위치만 보는 차단기(`m4_depth_filter.md` 의 오프라인 예측과 같은 방향입니다), 그리고 카메라 기울기가 바뀐 것입니다. 기울기가 얕아지면 깊이 오차가 위 축에 덜 섞입니다. 이번 시험만으로는 각각의 몫을 나눌 수 없습니다.
