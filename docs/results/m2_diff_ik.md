## 4. 해석

1. **특이점 분기 점프 제거 (`v2_cross` 오른손):**
   - A(`ArmIK` + clip)는 매 프레임 수렴할 때까지 반복 풀이한 뒤 관절별로 따로 속도를 자릅니다. `v2_cross` 오른손 `t = 4.30~4.93 s` 구간에서 `joint6`가 `-0.0381`~`-0.3739` rad(손목 특이점 통과)로 넘어가고 `joint2`도 `-0.1180` rad까지 0에 가까워지면서 `σ_min`이 `0.0177`까지 떨어집니다. 그 결과 수렴 해가 다른 분기로 뛰어 매 프레임 `joint1`은 최대 `+0.9206` rad, `joint3`는 `-1.1489` rad씩 반대 방향으로 돌라고 요구(`17.2255`~`34.4675` rad/s)하며, 팔이 그 분기를 뒤쫓느라 전체 수용 프레임의 `34.80%`가 속도 제한에 걸리고 위치 오차 p95가 `119.9643` mm까지 벌어집니다.
   - B(`DiffIK` 3.14 rad/s)는 새 기본 자세(`joint2 = -0.5`, `joint6 = 1.3` rad)와 적응 감쇠, 그리고 전체 `dq` 벡터의 균일 스케일링을 함께 써서 같은 구간에서 `joint2`를 `-0.9578`~`-0.3392` rad, `joint6`를 `+0.0425`~`+0.5639` rad(양수 영역 유지)로 지킵니다. 최소 `σ_min`은 전체 궤적에서 `0.0561`(`t = 4.30~4.93 s` 구간에서는 `0.0710`)로 A의 3배 이상을 유지하고, 스케일링 비율은 `34.80%`에서 `25.00%`로, 위치 오차 p95는 `119.9643` mm에서 `60.5050` mm로 절반 가까이로 줄어듭니다.
2. **운용 영역 안쪽(`v2_palm2`, `v2_back`) 추종 성능:**
   - B(`DiffIK` 3.14 rad/s)는 `v2_palm2` 양손과 `v2_back` 왼손에서 위치 오차 중앙값 `0.0091`~`0.0761` mm, p95 `0.2527`~`0.5604` mm를 기록하여, 수렴 허용오차(`pos_tol = 1` mm)에서 멈추고 상수 감쇠(`0.01`)를 쓰던 A보다도 낮은 위치 오차를 보입니다.
3. **1.0 rad/s 속도 제한(C)의 거동과 초기 수렴 시간:**
   - 첫 번째 수용 샘플(`Verdict.ACCEPT`) 기준으로 5 mm 이내에 들어오는 데 걸리는 시간은 `v2_palm`, `v2_palm2`, `v2_cross` 왼손에서는 B와 C 모두 첫 프레임(`0.0333` s)입니다.
   - 첫 프레임에 One Euro 필터 초기 구간 변위가 큰 `v2_back` 왼손(`0.1333` s -> `0.4000` s), `v2_back` 오른손(`0.0333` s -> `0.2000` s), `v2_cross` 오른손(`0.0333` s -> `1.1667` s)에서는 C(`1.0` rad/s)가 속도 상한을 엄격히 지키는 대신 따라잡는 데 `0.2000`~`1.1667` s가 걸립니다. 또한 손 이동 속도가 빠른 구간에서는 팔이 `1.0` rad/s로만 움직이므로 일시적인 추종 지연(p95 `13.3434`~`110.3971` mm)이 발생합니다.

## 5. 가정한 것과 하지 못한 것

- **가정한 것:**
  - `t = 0`(`Verdict.REENGAGE`)에서는 클러치가 현재 EEF 자세에 맞춰 기준을 잡으므로 정의상 오차가 0입니다. 따라서 "시작 후 5 mm 이내 도달 시간"은 실제 이동이 시작되는 첫 `Verdict.ACCEPT` 샘플부터 쟀습니다.
  - 카메라 내부 파라미터는 M1과 같은 근사값(`fx = fy = 600`)으로 추출된 `data/trajectories/v2_*.npz`를 그대로 사용했습니다.
  - 관절 속도 한계는 URDF 값(`3.14` rad/s)과 첫 실물 후보값(`1.0` rad/s)을 모든 7개 관절에 동일하게 적용했습니다.
- **하지 못한 것:**
  - 실물 xArm7에서의 서보 주기별 가속도·저크 제한과 통신 지연 측정은 포함하지 않았습니다(규칙상 실물 로봇·네트워크 접근 금지).
  - 양팔 동시 구동 시 두 팔 사이의 자기 충돌 회피와 Allegro Hand 장착 오프셋(`link_eef` -> `allegro_base`) 반영은 다음 단계 과제입니다.
