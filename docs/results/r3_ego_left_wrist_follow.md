# R3 (에고 시점): 왼팔이 RealSense 로 본 작업자 왼손을 따라가기

- 날짜: 2026-10-19
- 실행과 분석: Claude Opus 5.5 (총괄). 사용자 승인 후 진행했고, 사용자가 로봇을 지켜봤습니다.
- 카메라: `docs/05_ego_camera.md`. 시작 직전 IMU 측정에서 아래로 44.3°, 좌우 −5.1° 였습니다.

```bash
vision/hand_tracker_node_v2.py --source realsense --view ego --gpu
arm/arm_follow_node_v5.py --q0-from-robot --position-only --scale 0.5 --radius 0.07 --joint-box 0.3 \
    --max-joint-speed 0.3 --camera config/ego_camera.yaml
arm/xarm_bridge_node_v3.py --side left --enable --duration 32 --max-joint-speed 0.3 --max-excursion 0.3
```
