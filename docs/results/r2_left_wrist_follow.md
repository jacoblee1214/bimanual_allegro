# R2 결과: 왼팔이 작업자 왼손 위치를 따라가기 (첫 비전 구동 실물 시험)

- 날짜: 2026-10-19
- 실행과 분석: Claude Opus 5.5 (총괄). 사용자 승인 후 진행했고, 사용자가 웹캠 앞에서 손을 움직이며 로봇을 지켜봤습니다.
- 계획: `docs/03_arm_follow_design_v2.md` 4장 R2

## 1. 준비: 홈 이동

R2 dry run 에서 두 팔 모두 어깨 특이자세 근처에 있는 것이 드러났습니다. 2번 관절이 ±7° 였고, 최소 특이값이 0.035 였습니다(`results/r1_left_joint_nudge.md` 3장). 그래서 시뮬레이션 기본 자세와 같은 팔 끝 자세를 갖는 IK 해 가운데, 관절 한계 여유가 20° 이상이고 특이값이 0.15 를 넘으며 현재 관절에서 회전량이 가장 적은 해를 골랐습니다. 무작위 시작점 3,000개에서 구했습니다.

다음 두 단계를 거쳤습니다.
- 이동 경로 점검: 관절 공간 직선 보간을 따라가며 확인했습니다. 가장 낮은 지점은 base 면 위 160 mm(손 15 cm 가정), 두 팔 사이 최소 거리는 0.89 m 였습니다.
- 이동: `tools/move_joints.py` 로 컨트롤러 위치 모드에서 10°/s 로 움직였습니다.

| | 이동 전 σmin | 이동 후 σmin | 오차 | 팔 끝 (TCP, mm) |
|---|---|---|---|---|
| 왼팔 | 0.036 | **0.192** | 0.00° | (310, −2, 313) |
| 오른팔 | 0.035 | **0.208** | 0.03° | (309, −1, 313) |

팔 끝 도구 축은 거의 수직 아래를 향합니다. Argon 이 기본 자세를 고를 때 특이자세와 관절 여유를 기준으로 고른 결과이고, 작업을 보고 정한 방향은 아닙니다. 작업에 맞는 방향은 R3 전에 정합니다. 오른팔은 2번 관절이 한계까지 23° 남아 있습니다.

홈 이동 뒤 같은 녹화 영상으로 dry run 을 하면, 팔 끝 1 cm 에 관절이 약 0.03 rad 움직였습니다(3.1 rad/m). 이동 전에는 0.06~0.15 rad 였습니다.

## 2. R2 설정

```bash
xarm_bridge_node_v2.py --side left --enable --max-joint-speed 0.3 --max-excursion 0.15   # 38 s 뒤 SIGINT
arm_follow_node_v2.py --q0-from-robot --position-only --max-joint-speed 0.3
hand_tracker_node.py --source 0 --camera-info config/camera_nominal_640x480.yaml --gpu
```

- 위치만 따라가고, 팔 끝 방향은 클러치를 건 순간의 방향으로 고정했습니다.
- 카메라 파라미터는 근사값(fx = 600)입니다.

## 3. 결과

| 항목 | 값 |
|---|---|
| 손 검출 | 893/893 프레임 (29.6 fps), 손목 샘플 1,023개 모두 통과 (거부 0, 재클러치 1 = 시작) |
| 손목 이동 범위 (카메라 x / y / z) | 23 / 27 / 15 mm |
| 팔 끝 이동 범위 (엔코더 + URDF, base y / z / x) | 23 / 26 / 15 mm, 시작점에서 최대 23 mm |
| 축 대응 상관계수 | 카메라 −z → base x **+0.97**, 카메라 x → base y **+1.00**, 카메라 −y → base z **+0.99** |
| 관절 변화 최대 | 0.049 rad (상자 0.15 rad 안, 상자에 걸린 명령 0) |
| 관절 속도 최대 | 0.262 rad/s (제한 0.3) |
| 팔 끝 속도 | 최대 75 mm/s, p95 27 mm/s |
| 지연 (추종 노드 명령 → 엔코더) | 약 90 ms |
| 끝난 뒤 | state 4, 오류 0 |

설계 v1 2장의 `R_CB` 가 실제 배치에서도 맞았습니다. 작업자가 카메라를 보고 앉아 있고, 로봇은 작업자와 같은 쪽을 보는 배치입니다. 손을 앞으로 내밀면 팔이 앞으로, 손을 왼쪽으로 옮기면 팔이 왼쪽으로, 손을 올리면 팔이 위로 갑니다.
