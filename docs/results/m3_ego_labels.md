# M3 결과: 에고 시점에서 좌우 판별

- 날짜: 2026-10-19
- 실행과 분석: Claude Opus 5.5 (총괄). 사용자가 화면 지시에 따라 손을 움직였습니다.
- 장비: RealSense D457 컬러 640x480@30 (USB 2), 아래로 약 44°, 작업자 머리 뒤쪽 위
- 검출기: MediaPipe Tasks API (GPU)
- 원자료: `data/clips/ego_labels.avi`, `.jsonl` (git 미포함)

```bash
.venv-vision/bin/python tools/check_labels_ego.py
```

순서: 준비 5 s → 오른손만 10 s → 왼손만 10 s → 두 손(교차 없이) 12 s.

## 1. MediaPipe 라벨

| 단계 | 검출 | 라벨 정답률 | 점수 중앙값 | 손목 x 중앙값 |
|---|---|---|---|---|
| 오른손만 | 300/300 | 82% | 0.83 | 0.70 |
| 왼손만 | 285/301 | 70% (x < 0.2 에서 89%, 0.2~0.4 에서 48%) | 0.80 | 0.17 |
| 두 손 | 두 손 모두 199/360, 한 손만 161 | 서로 다른 라벨 128/199 | | |

- 틀린 라벨의 점수: 오른손 중앙값 0.76 / 최대 0.97, 왼손 0.79 / 0.96. 점수로는 걸러낼 수 없습니다(정면 V2 와 같은 결론).
- 점수 0.8 이상만 남기면 검출의 49~64% 만 남는데도 정답률은 71~89% 에 그칩니다.
- 정면 웹캠에서는 화면 가운데 영역에서 라벨이 0% 틀렸습니다(설계안 V2). 뒤에서 손등을 보는 에고 시점에서는 라벨이 크게 나빠집니다.

## 2. 위치

- 두 손이 함께 잡힌 199 프레임에서 두 손목 사이 x 간격은 최소 0.58, 중앙값 0.64 였습니다.
- 위치 규칙(화면 오른쪽이 오른손)의 정답률은 오른손 단계 100% 입니다.
- 왼손 단계에서는 오른쪽에 잡힌 29 프레임이 있었는데, 모두 단계 시작 첫 1초(15.0~15.9 s)에 몰려 있었고 왼쪽에는 손이 없었습니다. 아직 내리지 않은 오른손으로 보이므로, 이 경우 위치 규칙의 판단이 맞습니다.

## 3. 같은 영상에 두 규칙을 돌린 결과

| 규칙 | 오른손 단계: right 발행 / 틀린 left | 왼손 단계: left 발행 / right | 두 손 단계: 양쪽 다 발행 |
|---|---|---|---|
| **위치 (`EgoHandTracker`)** | 300/300 / 0 | 256/301 / 35 (첫 1초의 실제 오른손 포함) | 199/360 |
| 라벨 (기존 `HandTracker`) | 186/300 / 26 | 112/301 / 41 | 43/360 |

에고 시점에서는 위치 규칙을 씁니다. 남은 약점은 두 손이 함께 잡히는 비율(55%)입니다. 카메라 배치, USB 3 해상도, 깊이 사용으로 다시 볼 부분입니다.

## 4. 전체 경로 dry run

- 구성: 녹화한 에고 영상을 반복 재생하며 비전 v2(`--view ego`) → 추종 v5(`--camera config/ego_camera.yaml`) → 브리지 v3(명령 미전송) 을 32 s 돌렸습니다.
- 오른손만 보이는 앞 15 s 동안 왼팔 명령은 시작 자세 그대로였고, 왼손이 나오면서 명령이 움직였습니다.
- 범위 밖 명령은 0, 브리지는 32 s 에 스스로 종료했습니다.
