# R3 결과: 왼팔 손 추종, 범위 ±0.3 rad (첫 시도)와 손 방향 전환

- 날짜: 2026-10-19
- 실행과 분석: Claude Opus 5.5 (총괄). 사용자 승인 후 진행했고, 사용자가 로봇을 지켜봤습니다.

## 1. 손 방향 전환 (R3 전)

R2 까지는 손끝이 아래를 향했습니다. 사용자 지적대로 사람처럼 좌우 손을 쓰려면 손끝이 앞을 향하고, 손바닥이 사람 손과 같은 쪽을 봐야 합니다. 사용자와 정한 목표는 **손끝 앞(+x), 손바닥 아래(−z)** 입니다.

손이 아래를 향한 자세에서 손바닥은 앞을 보고 있었습니다(사용자 확인). 그래서 앞으로 숙이기만 하면 손바닥이 위를 보게 됩니다. 손 축 둘레로 180° 를 더 돌려야 했고, 한 번에 가면 관절 회전이 177~193° 라서 두 단계로 나눴습니다.

| 단계 | 동작 | 최대 회전 | 경로 최저점 (손 28 cm 가정) | 결과 |
|---|---|---|---|---|
| 1 | 7번 관절만 +180° | 180° | 107 mm | 오차 0.12°, 오류 0 |
| 2 | 앞으로 숙이기, 팔 끝 5 cm 올림 | 99° | 105 mm | 오차 0.00°, 오류 0 |

모델 기준 손끝 방향은 (0.999, 0.00, 0.05), 손바닥 방향은 (−0.05, 0.01, −0.999), σmin 은 0.171 입니다. 첫 시도 때 `move_joints.py` 가 "계산 이후 2.4° 움직였다"며 실행을 거부했습니다. R2 의 손 추종으로 팔이 옮겨진 뒤였기 때문이고, 현재 자세로 다시 계산해 진행했습니다.

## 2. R3 첫 시도: 손이 화면에 없음

웹캠 화면에 손이 들어오지 않아 869 프레임 중 왼손 2 프레임만 잡혔습니다. 작업자 얼굴이 화면 아래 끝에 있었고, 창문 역광도 있었습니다. 팔은 계속 "제자리 유지"만 받았고, 정지(state 4)에 오류 0 으로 끝났습니다.

## 3. R3 두 번째 시도: 안전장치는 동작, 추종은 나쁨

설정: `arm_follow_node_v2.py --position-only --max-joint-speed 0.3`, 브리지 `--max-excursion 0.3 --max-joint-speed 0.3`, 30초.

| 항목 | 결과 |
|---|---|
| 손 검출 | 753/892 프레임, 손목 샘플 거부 0 |
| 손 움직임 | 최대 23 cm, 손목 속도 p95 0.55 m/s. 카메라 깊이 방향 범위 31 cm |
| 팔 끝 | 최대 101 mm (축별 범위 89~100 mm) |
| 관절 속도 (50 ms 구간) | 최대 0.33 rad/s (상한 0.3) |
| 한 주기 최대 관절 변화 | 0.0048 rad, 0.01 rad 넘는 걸음 0 |
| 축별 상관 (앞뒤 / 좌우 / 상하) | 0.31 / 0.69 / 0.20 (R2: 0.97 / 1.00 / 0.99) |
| 범위 밖 명령 | 1,378회 무시, 마지막 약 15초 정지 |
| 끝난 뒤 | state 4, 오류 0 |

**측정 오류 하나:** 처음 분석에서 관절 속도가 8.56 rad/s 로 나왔습니다. 기록기가 도착 시각으로 시간을 찍었고, 두 메시지가 0.3 ms 간격으로 몰려 도착한 탓이었습니다. 위 표는 50 ms 구간으로 다시 계산한 값입니다. 이후 기록기는 메시지 헤더 시각을 씁니다.

**추종이 나빴던 이유**
1. 손이 팔의 한계(약 10 cm, 약 10 cm/s)보다 훨씬 크고 빠르게 움직였습니다. 팔이 계속 뒤처지고 범위 끝에 걸렸습니다.
2. 추종 노드는 브리지의 범위 상자를 몰랐습니다. 그래서 상자 밖까지 목표를 계속 따라갔고, 브리지는 그 명령을 통째로 무시했습니다. 추종 노드의 상태가 상자 밖에 있는 동안 팔이 멈췄습니다. 안전하지만, 조작하는 쪽에서는 팔이 반응하지 않는 것으로 보입니다.

## 4. 고친 것: `arm/arm_follow_node_v3.py`

- `--radius`: 목표 팔 끝을 클러치 기준점에서 반경 안으로 자릅니다. 팔은 범위 끝을 따라 미끄러지고 멈추지 않습니다.
- `--scale`: 손 움직임을 줄여서 팔에 넘깁니다.

`--radius 0.07 --scale 0.5` 로 가장자리 영상(가장 거친 입력)을 dry run 한 결과입니다.

| 팔 끝 명령 최대 | 82 mm |
